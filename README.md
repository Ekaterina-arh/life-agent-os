A personal experimental system for adaptive micro-decision support.

LIFE AGENT OS explores how software, data and AI can help a person choose the next useful action under real-life constraints.

The project experiments with a feedback loop:

GOAL → STATE → PROPOSAL → HUMAN DECISION → ACTION → RESULT → FEEDBACK → ADAPTATION

Current focus:

* Python
* data and experimentation
* SQLite
* software architecture
* AI-assisted decision support
* human-in-the-loop systems

Initial research question:

Can a system improve its ability to choose useful next actions by learning from a person's decisions and outcomes?

This is an experimental personal project, not a finished productivity product.
