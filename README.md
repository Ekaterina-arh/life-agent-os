# LIFE AGENT OS

A personal experimental system for adaptive micro-decision support.

LIFE AGENT OS explores how software, data, and AI can help a person choose the next useful action based on their goals, current state, available resources, and real-life constraints.

The system uses a feedback loop:

**GOAL → STATE → PROPOSAL → HUMAN DECISION → ACTION → RESULT → FEEDBACK → ADAPTATION**

The initial experiment asks:

**Can a system improve its ability to recommend useful next actions by learning from a person's decisions and outcomes?**

Current focus:

* Python
* data and experimentation
* SQLite
* software architecture
* AI-assisted decision support
* human-in-the-loop systems

This is a personal experimental project and learning laboratory, not a finished productivity product.
